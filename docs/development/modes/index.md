# Agent working modes

Use these short instructions with any coding assistant. They inherit the [constitution](../constitution.md) and the task's actual scope and authorization. They do not grant tools, external access, or permission to make changes.

- [EXPLORE](explore.md): clarify outcomes and unknowns.
- [EXPERIMENT](experiment.md): test a hypothesis without claiming production acceptance.
- [DESIGN](design.md): settle boundaries and create an executable slice.
- [STRICT MODE](strict.md): implement accepted requirements faithfully.
- [REVIEW](review.md): compare the implementation with the contract and evidence.

The [lifecycle](../guides/lifecycle.md) defines phases consistently. A small task may use several activities in one short pass. Do not claim to have entered another mode as a substitute for performing its work.
